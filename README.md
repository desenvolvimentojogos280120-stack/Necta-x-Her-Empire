# 💜 Necta+

Plataforma de conexão, apoio e aprendizado para mulheres empreendedoras.

## 🚀 Como acessar

Abra o arquivo `index.html` no navegador ou publique pelo GitHub Pages.

## ✨ Funcionalidades

- Cadastro e login demonstrativos
- Confirmação de e-mail
- Página inicial
- Mapa de Recife
- Categorias de negócios
- Publicação de produtos
- Mensagens demonstrativas
- Necta IA demonstrativa
- Cursos
- Perfil da empreendedora
- Favoritos
- Modo escuro
- Acessibilidade em Libras (painel ilustrativo)

## 🎨 Identidade visual

- Roxo: `#7C3AED`
- Rosa: `#F9A8D4`
- Rosa escuro: `#EC4899`
- Branco: `#FFFFFF`

## 📱 Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- OpenStreetMap

## ⚠️ Aviso

Este projeto é um protótipo demonstrativo. Login social, envio real de e-mail, mensagens entre usuárias, inteligência artificial conectada e tradução em Libras ainda precisam de integração com serviços externos.

Os dados de exemplo não representam informações reais ou locais de segurança verificados.

## 💜 Objetivo

Conectar mulheres, fortalecer negócios e criar oportunidades para empreender com mais apoio e segurança.

**Necta+ — Conectando mulheres empreendedoras.**
